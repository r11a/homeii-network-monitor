# Security Policy

Security fixes are applied to the current 6.x release line.

Please use GitHub private vulnerability reporting. Do not publish network details, Home Assistant credentials, private device data or proof-of-concept exploits in a public issue.

HOMEii can run diagnostics against the local network. Direct Web access on port `8383` is protected by a HOMEii username and password; expose it only to trusted networks. Home Assistant Ingress uses the authenticated Home Assistant identity.
